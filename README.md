# Open Reconstruction Suite

**Status:** v0.1 MVP — pre-alpha

Open Reconstruction Suite (ORS) is a vendor-agnostic real-time ray-tracing denoiser and upscaler for cross-platform games and interactive applications. See [docs/specs/2026-04-29-design.md](docs/specs/2026-04-29-design.md) for the full technical design. Licensed under Apache-2.0.
