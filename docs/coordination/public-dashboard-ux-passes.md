# Public dashboard UX passes

Pass 1/5 - above-the-fold clarity. Screenshots showed the required status cards and measured number above the fold, but the pitch read as a DLSS/FSR critique rather than a one-sentence project description. The dashboard now uses a concise OpenSuperSampling pitch focused on unified super-resolution and frame extrapolation. After screenshots: `/tmp/pass-1-after-desktop.png`, `/tmp/pass-1-after-tablet.png`, `/tmp/pass-1-after-mobile.png`.

Pass 2/5 - information density vs whitespace. Desktop screenshots showed the at-a-glance cards stretching to the GPU panel height, leaving empty space that looked unfinished. The summary grid now aligns items to their natural height so the top section reads tighter. After screenshots: `/tmp/pass-2-after-desktop.png`, `/tmp/pass-2-after-tablet.png`, `/tmp/pass-2-after-mobile.png`.

Pass 3/5 - mobile experience. The 390x844 screenshot showed horizontal overflow from chart and viz containers inside the open run accordion. The run detail grid, chart wrapper, and nested cards now use `min-w-0` and canvas width guards; Playwright reported mobile `scrollWidth` equal to the viewport width. After screenshots: `/tmp/pass-3-after-desktop.png`, `/tmp/pass-3-after-tablet.png`, `/tmp/pass-3-after-mobile.png`.

Pass 4/5 - loss-curve legibility. The chart used separate axes, but the right axis was labeled only `LPIPS` even though it also carried Charbonnier, making the component series ambiguous. The right axis is now labeled `component loss`, with the component lines styled separately from total loss. After screenshots: `/tmp/pass-4-after-desktop.png`, `/tmp/pass-4-after-tablet.png`, `/tmp/pass-4-after-mobile.png`.

Pass 5/5 - accordion skim signal. Closed history rows showed run names and statuses, but did not clearly advertise what a reviewer would get by opening them. Historical summaries now call out the measured v5 numbers, v4 SRGD/latency baseline, and v6 grid-artifact evidence, with an `Open details` cue on desktop. After screenshots: `/tmp/pass-5-after-desktop.png`, `/tmp/pass-5-after-tablet.png`, `/tmp/pass-5-after-mobile.png`.

Pass 6 - live polling, no page reload. The dashboard now re-fetches `/data.json?t=<Date.now()>` every 30 seconds, destroys and rebuilds Chart.js instances before re-rendering, preserves open run accordions across refreshes, and recomputes the `updated X ago` stamp every 5 seconds from `generated_at`. Network failures keep the last-known render in place and show `Connection lost — retrying` until a later poll succeeds. After screenshots: `/tmp/oss-dashboard-ux/pass-6-after-desktop.png`, `/tmp/oss-dashboard-ux/pass-6-after-tablet.png`, `/tmp/oss-dashboard-ux/pass-6-after-mobile.png`.

Pass 7 - live training pulse and step tape. The active run now derives `live` versus `idle` from fresh `generated_at` data plus a newly advanced step since the prior poll. Fresh step advances show a pulsing `● live` indicator, a latest-three-step tape with a slide/fade row entry, and a short-lived highlight ring on the newest total-loss point; `prefers-reduced-motion: reduce` disables the pulse and tape animation. After screenshots: `/tmp/oss-dashboard-ux/pass-7-after-desktop.png`, `/tmp/oss-dashboard-ux/pass-7-after-tablet.png`, `/tmp/oss-dashboard-ux/pass-7-after-mobile.png`.

Pass 8 - reactive hover and click details. Viz frames now lift on hover, reveal the step overlay, and open in a vanilla `<dialog>` lightbox with keyboard close/navigation; loss-curve tooltips report all key losses and GPU status when available; metric cards expand on click to show a last-100-point sparkline; run accordions use explicit max-height animation instead of a jump cut. After screenshots: `/tmp/oss-dashboard-ux/pass-8-after-desktop.png`, `/tmp/oss-dashboard-ux/pass-8-after-tablet.png`, `/tmp/oss-dashboard-ux/pass-8-after-mobile.png`.

Pass 9 - de-AI palette and typography. The visual language moved away from Tailwind-default slate/cyan cards toward a dark navy console surface, a single phosphor-green UI accent, Atkinson Hyperlegible body text, IBM Plex Mono numerics, sharper stat-card geometry, 4px viz rounding, verb-led section framing, and one ASCII OSS mark as the visual anchor. After screenshots: `/tmp/oss-dashboard-ux/pass-9-after-desktop.png`, `/tmp/oss-dashboard-ux/pass-9-after-tablet.png`, `/tmp/oss-dashboard-ux/pass-9-after-mobile.png`. Final live sweep screenshots: `/tmp/oss-dashboard-ux/passes-6-9-final-desktop.png`, `/tmp/oss-dashboard-ux/passes-6-9-final-tablet.png`, `/tmp/oss-dashboard-ux/passes-6-9-final-mobile.png`.

Pass 10 - click-zoom modal refinement. The baseline viz-strip lightbox was present, so this pass locked page scrolling while the modal is open and verified viewport coverage on desktop 1280x900 and mobile 390x844. Playwright checked click open, ESC close, explicit close, and ArrowLeft/ArrowRight cycling through a run's step-ordered strips. Evidence: `/tmp/pass-13-after-mobile-lightbox.png`.

Pass 11 - pixel magnifier. The lightbox now has a default-on mouse magnifier toggle that renders a 200x200 circular 4x source-pixel view with `image-rendering: pixelated`; the toggle hides the lens and restores the regular cursor when off. Touch/mobile contexts auto-disable the control. Playwright verified visible pixelated background rendering on desktop and disabled state on 390x844 touch.

Pass 12 - mobile pinch zoom. The lightbox image container now uses `touch-action: none` with vanilla pointer-event handling for two-finger pinch zoom from 1x to 8x, one-finger pan while zoomed, and double-tap between fit and 2x. Synthetic touch PointerEvents on a 390x844 mobile Playwright context verified double-tap scale, pan translation, and pinch scale changes.

Pass 13 - mobile dashboard polish. A 390x844 touch Playwright review found no page-level horizontal overflow, 130px run-history summary tap targets, a tappable chart tooltip, and a full-screen 390x844 lightbox with the magnifier disabled on touch. The viz strip gained x-axis overscroll containment, touch pan-x, momentum scrolling, and scroll snap so horizontal gallery swipes do not leak into page scroll. Evidence: `/tmp/pass-13-after-mobile-hero.png`, `/tmp/pass-13-after-mobile-chart-tap.png`, `/tmp/pass-13-after-mobile-viz-strip.png`, `/tmp/pass-13-after-mobile-lightbox.png`.

Pass 14 - Multi-Magnify, operator spinner, terminal logo, and expanded metrics. The lightbox now defaults to Multi-Magnify with `v6.1` versus `v5-pixel-temporal`, 2x side-by-side 140px lenses, column selectors, zoom choices, and touch auto-disable while preserving pinch zoom. The operator-supplied loader CSS is inlined and recolored as the active-training spinner, with a full-size first-load state and gray idle fallback. The dashboard also now publishes `viz_columns` and `max_target_steps`, backfills the v5 held-out row, shows active-run training progress, and renders live PSNR, live LPIPS, held-out PSNR/LPIPS, and loss-decomposition charts. Playwright verified no mobile horizontal overflow, the default compare selectors, and 15 rendered canvases. Evidence: `/tmp/oss-dashboard-ux/ux-current-desktop.png`, `/tmp/oss-dashboard-ux/ux-current-tablet.png`, `/tmp/oss-dashboard-ux/ux-current-mobile.png`, `/tmp/oss-dashboard-ux/ux-current-lightbox-multimagnify.png`.

Pass 15 - OSS ASCII logo completion. The tracked `oss-logo.svg` now spells the full `OPEN / SUPER / SAMPLING` wordmark in the white-accent-white pattern instead of truncating the final word to `SAM`. Evidence reused from the current visual pass: `/tmp/oss-dashboard-ux/ux-current-desktop.png`, `/tmp/oss-dashboard-ux/ux-current-mobile.png`.

Pass 16 - Multi-Magnify finalization. The lightbox magnifier now renders two 140px canvas lenses side by side from user-selected comparison columns, defaults to `v6.1` versus `v5-pixel-temporal`, and uses pixel-pitch language: `200% — 1 source px → 2×2 display px • covering 70×70 source pixels per circle`. Mouse hover shows both lenses; touch keeps Multi-Magnify hidden so pinch zoom remains the mobile interaction. Evidence: `oss-final-lightbox-multimagnify.png`.

Pass 17 - ASCII loader replacement. The ball-spinner path was removed from the public dashboard CSS and active training now uses the `[░░░] → [█░░] → [██░] → [███]` block-fade spinner with a blinking block cursor. Stale or idle training renders as static `[___] idle`, and `prefers-reduced-motion: reduce` freezes the animation. Evidence: `oss-final-desktop.png`, `oss-final-mobile.png`.

Pass 18 - cross-version industry-context chart. A top-level `Held-out PSNR / LPIPS by version` chart now plots measured OSS v4, v5, and v6.1 points, annotates v6 as not measured, and overlays conservative DLSS / FSR / XeSS reference lines with source attribution. The default visible set is kept small: OSS points, bicubic PSNR/LPIPS, and latest-vendor PSNR references; older generations and denser LPIPS references are available through `Show all generations`, and `Full range` switches out of auto-zoom. Final Playwright checks showed PSNR auto-scale 22-35 dB, LPIPS auto-scale 0.07-0.33, no horizontal overflow, and 44px mobile chart toggles. Evidence: `oss-final-desktop.png`, `oss-final-mobile-comparison-r4.png`.

The dashboard now uses the requested `#06110f` / `#8cffc1` terminal palette, a faint scanline overlay at `rgba(255,255,255,0.018)`, low-strength phosphor inset glow on major panels, ASCII section dividers, and the block cursor treatment on live indicators. The screenshots remained readable on desktop, tablet, and mobile without drifting into novelty-page density. Evidence: `oss-final-desktop.png`, `oss-final-tablet.png`, `oss-final-mobile.png`.
