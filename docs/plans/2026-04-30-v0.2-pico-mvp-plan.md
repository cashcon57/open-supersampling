# ORS v0.2-pico MVP Implementation Plan

> Minimal viable v0.2: ORU-Pico (Steam Deck tier) + Vulkan inference + gamescope integration. Tightest scope to demonstrate "ML upscaler runs on Steam Deck better than FSR 1." DLL swap, multi-tier weights, Windows build, per-game compat all defer to v0.2-beta.

**Goal:** Prove the architecture story end-to-end with the smallest deliverable. ORU-Pico trained on NoiseBase (+ QRISP if licensable), exported to ONNX, ran via Vulkan compute, integrated with gamescope, deployed on Steam Deck, side-by-side quality test vs gamescope FSR 1.

**Architecture:** Build on v0.1 PyTorch reference. ORU-Pico = ~250-300K param kernel-prediction U-Net with temporal-recurrent state, FP16-packed-friendly channel widths for RDNA 2. Vulkan inference via HLSL → DXC → SPIR-V. gamescope plugin loads SPIR-V at runtime.

**Tech Stack:** Python 3.12, PyTorch 2.4+, ONNX, Vulkan 1.3, HLSL/DXC, gamescope, Lambda Labs (Linux+CUDA training), Steam Deck (deployment target).

**Total effort:** ~3-5 weeks. ~$50-100 cloud GPU. Plus Steam Deck dev time.

## Task 2 — ORU-Pico architecture (~250-300K params)

**Goal:** New PyTorch `nn.Module` for Steam Deck tier. Kernel-prediction U-Net + recurrent latent state. Channel widths multiples of 8 for FP16-packed RDNA 2.

**Files:** `ors/model/oru_pico.py`, `tests/test_oru_pico.py`.

**Architecture:**
- Stages [16, 24, 32, 40] (encoder/decoder mirror)
- Recurrent state: 24-channel hidden tensor at bottleneck level, GRU-cell update
- Two-branch input: low-res RGB+history (6 ch) + G-buffer (5 ch: depth, motion-2, normals-2-after-projection)
- Kernel-prediction head: 5×5 weights, softmax-normalized, applied via F.unfold to bilinearly-upsampled input
- Output: high-res RGB

**Acceptance criteria:**
- `ORUPico().forward(color_lr, depth_lr, motion_lr, normals_lr, history_hr, hidden_state)` returns `(rgb_hr, new_hidden_state)`
- Param count between 250K and 320K
- All channels multiples of 8
- Backward gradients flow through both outputs

**Verify:** `pytest tests/test_oru_pico.py -v`

**Steps:**

1. Write failing tests asserting forward signature, output shapes, param count bounds, gradient flow.
2. Implement `ORUPico` reusing `ConvBlock`/`DownBlock`/`UpBlock`/`KernelPredictionHead` from `ors/model/blocks.py`.
3. Add a `RecurrentLatentCell` primitive in `ors/model/temporal.py` (GRU-cell over a 4D feature tensor).
4. Run tests, verify param count.
5. Commit.

## Task 3 — Training pipeline (temporal + composite loss)

**Goal:** Trainer that walks NoiseBase sequences, unrolls ORU-Pico over N frames with hidden-state propagation, computes composite loss (relative-L2 + SSIM + temporal-consistency).

**Files:** `ors/train/train_pico.py`, extension of `ors/train/losses.py`.

**Acceptance criteria:**
- `train_pico.py --smoke-test` runs 50 steps on synthetic data, saves a checkpoint
- Loss = relative_l2(pred, gt) + 0.1*(1-SSIM) + 0.1*temporal_consistency(pred_t, pred_{t-1}, motion)
- Hidden state propagates correctly across frames within a sequence (zeroed at sequence boundary)

**Verify:** `python -m ors.train.train_pico --smoke-test`

**Steps:**

1. Add `temporal_consistency_loss` to `ors/train/losses.py`: warps pred_{t-1} via motion vectors, penalizes per-pixel difference vs pred_t.
2. Write `train_pico.py` mirroring `train_paired.py` structure but with sequence unrolling.
3. Smoke test with synthetic random tensors.
4. Verify checkpoint saves correctly.
5. Commit.

## Task 7 — Vulkan compute inference (gamescope-friendly)

**Acceptance criteria:**
- HLSL kernels compile to SPIR-V via DXC
- Python runtime can run SPIR-V inference via vulkan-py
- Output matches ONNX inference within FP16 tolerance
- Inference latency on RTX 3080 Ti: target <2ms at 540p→800p

**Verify:** `python -m ors.inference.vulkan.runtime --bench` on Tailscale-accessible Windows box.

**Blocking:** Tailscale hostname for Windows test box (for benchmarking; local Linux Vulkan validation works on dev box first).

**Steps:**

1. Write HLSL kernels mirroring ORU-Pico architecture (conv2d, group norm, SiLU, transpose-conv-as-bilinear-upsample, kernel-prediction).
2. Compile via DXC: `dxc -spirv -E main -T cs_6_2 ...`
3. Build Vulkan runtime in Python (vulkan-py or PyVulkan).
4. Validate output matches PyTorch + ONNX.
5. Bench latency on RTX 3080 Ti.
6. Commit.
